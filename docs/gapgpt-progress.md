# پیشرفت مقاییس

**1370 مدخل تأییدشده و آمادهٔ استفاده است.** فقط ریشه‌های قرآن در خروجی هستند. اشتقاقی شروع نشده است.

وضعیت فعلی: **توقف به دلیل خطای ۴۰۳ سرویس API**. Argon و سپس یک درخواست تک‌مدخلی Flash رد شدند؛ پاسخ سرویس فقط `api_provider_error / request failed` است و علت دقیق را اعلام نمی‌کند. هزینهٔ محلیِ پاسخ‌های موفق تقریباً ۱۰ دلار شده؛ رسیدن به سقف کلید محتمل است، اما اثبات نشده است. تا رفع خطای سرویس درخواست پولی دیگری ارسال نمی‌شود.

از 1525 ریشهٔ دارای مأخذ قابل تطبیق، **155 ریشه** باقی مانده است. **117 صورت ریشه** نیز مأخذ مستقلِ قابل تطبیقِ مطمئن ندارد یا فقط حاشیه در دسترس است؛ این موارد ترجمه‌شده محسوب نمی‌شوند.

هزینهٔ پاسخ‌های موفق طبق دادهٔ API: **9.9990958 دلار**. هزینه با تمام رزروهای نامشخص: **10.3530336 دلار**. کاربر مبلغ حساب را پیش‌تر نزدیک ۱۲ دلار گزارش کرده بود؛ این اختلاف هنوز تطبیق نشده است و آمار محلی، صورت‌حساب قطعی ارائه‌دهنده نیست.

بودجهٔ تازهٔ مجاز **۳ دلار اضافه** است. مصرف محلیِ مرحلهٔ تازه با رزروها **1.3061786 دلار** است. برای اختلاف حساب، ضریب احتیاط ۱٫۵ اعمال شده و سقف مصرف محلی تازه ۲ دلار است؛ این ضریب، کارمزد اثبات‌شدهٔ سرویس نیست. رزروهای درخواست‌های ردشده صفر فرض یا آزاد نشده‌اند.

مترجم پایه Luna و ناظر Flash است؛ اصلاح‌های پایدار به Flash سپرده می‌شوند و مدل اصلاح در مأخذ ثبت می‌شود. متن جدید ممکن است شامل متن مؤلف و حواشی مرجع باشد؛ این موضوع در هر مدخل توضیح داده شده است. بازبینی انسانی یا کامل‌بودن متن اصلی کتاب ادعا نمی‌شود.

بسته‌های تأییدشده به `main` ارسال شده‌اند؛ آماده‌شدن دیپلوی Vercel از این محیط بررسی نشده است. ادامه پس از رفع دسترسی API باید با حفظ همین دفتر هزینه و بودجهٔ اضافه انجام شود؛ سابقهٔ هزینه نباید پاک یا دوباره صفر شود.
