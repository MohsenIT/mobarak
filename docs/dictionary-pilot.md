# آزمایش ۵۰ مدخل با GPT-5 mini

این ابزار فقط آزمایش جداگانه می‌سازد؛ دادهٔ سایت و ترجمه‌های فعلی را تغییر نمی‌دهد. مدل در این آزمایش `gpt-5-mini` است، با reasoning کم. داده‌های کتاب ورودی ترجمه‌اند، نه دستور اجرایی.

## نمونه‌ها و مقایسه

۲۵ مدخل مقاییس و ۲۵ مدخل اشتقاقی از ترجمه‌های موجود در یک commit ثابت انتخاب می‌شوند. انتخاب بر اساس طول مرتب شده و از کوتاه تا بلند را پوشش می‌دهد. شناسه‌ها تکراری نیستند. ترجمهٔ فعلی فقط برای مقایسه نگه داشته می‌شود؛ برای مدل ارسال نمی‌شود و مرجع قطعی صحت علمی هم محسوب نمی‌شود.

خروجی مدل باید برای هر بند عربی یک بند فارسی و یک خلاصهٔ جدا داشته باشد. پاسخ ناتمام یا دارای تعداد بند نادرست پذیرفته نمی‌شود. این کنترل ساختاری به معنی تأیید وفاداری معنایی نیست. پس از اجرا، حذف مطالب، اصطلاح‌های لغوی، شواهد، عددها، ارجاع‌ها و خوانایی باید در کنار متن عربی بررسی شوند. هیچ خروجی بدون این بررسی وارد سایت نمی‌شود.

## اتصال امن

نیاز `QURAN_TRANSLATION_API_KEY` برای مقصد HTTPS `api.openai.com` در پیش‌نویس تنظیمات محیط ثبت شده است. مقدار کلید فقط در تنظیمات امن وارد شود؛ نه در چت، فایل یا Git. نام `OPENAI_API_KEY` برای ثبت این اتصال در پلتفرم رزرو شده است، بنابراین ابزار از نام مخصوص پروژه استفاده می‌کند. برای اجرای خارج از این محیط، خواندن متغیر استاندارد OpenAI نیز پشتیبانی می‌شود.

ذخیرهٔ نیاز به کلید، اعتبار API ایجاد نمی‌کند و به معنی اتصال موفق نیست. پس از واردکردن کلید، تنظیمات باید ذخیره و محیط Publish شود؛ اجرای زنده فقط پس از بررسی دسترسی انجام می‌شود. اعتبار API از اشتراک ChatGPT جداست.

## اجرا

```sh
python3 scripts/pilot-dictionary-translation.py prepare
python3 scripts/pilot-dictionary-translation.py run
python3 scripts/pilot-dictionary-translation.py report
```

فایل‌ها در `/workspace/.translation-jobs/quran-vajeh/gpt5-mini-pilot` نگه داشته می‌شوند:

- `samples.json`: متن عربی، ترجمهٔ مبنا، SHA256 و commit ثابت.
- `requests.jsonl`: ۵۰ درخواست آماده با قالب Batch API؛ آماده‌سازی آن هیچ درخواستی ارسال نمی‌کند.
- `results/<id>/`: پاسخ، مصرف توکن و وضعیت هر درخواست.
- `report.json`: تعداد تکمیل‌شده، مصرف واقعیِ گزارش‌شدهٔ API، زمان درخواست‌ها و هشدارها؛ حکم کیفیت تا بازبینی «ارزیابی‌نشده» است.

حداکثر ۵ درخواست هم‌زمان مجاز است؛ پیش‌فرض ۳. خروجی موفق دوباره درخواست نمی‌شود. درخواست شکست‌خورده یا قطع‌شده ممکن است هزینه داشته باشد، بنابراین تکرار آن فقط با `--retry-failed` انجام می‌شود. هزینهٔ دلاری تا تأیید نرخ جاری و صورتحساب محاسبه نمی‌شود؛ مقدار ساختگی درج نمی‌شود. تعداد توکن خروجی شامل مصرفی است که خود API در usage گزارش می‌کند.

## اعتبارسنجی

```sh
python3 scripts/test-dictionary-pilot.py
```

آزمون‌ها آفلاین‌اند: ارسال‌نشدن ترجمهٔ مبنا، قالب درخواست، رد خروجی ناقص، ثابت‌ماندن نمونه‌ها، جلوگیری از فراخوانی بدون کلید و جلوگیری از تکرار ناخواسته را بررسی می‌کنند. موفقیت این آزمون‌ها، اجرای زندهٔ GPT-5 mini یا مناسب‌بودن کیفیت ترجمه را اثبات نمی‌کند.
