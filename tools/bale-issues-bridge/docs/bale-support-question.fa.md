# یادداشت تاریخی — مانع عضویت با رابط رسمی وب رفع شد

این متن پیش از ورود مالک و افزودن موفق بات به گروه آماده شده بود؛ وضعیت جاری در PHASE_ZERO.md است و این متن درخواست فعال پشتیبانی نیست.

# متن آماده برای بررسی توسط پشتیبانی رسمی بله

هدف: خواندن و نوشتن دیدگاه بومی پست کانال با Bot API رسمی، بدون حساب انسانی شبیه‌سازی‌شده.

بات آزمایشی: @mobarak_bot
کانال آزمایشی: @mobarak_issues

بات مدیر کانال است؛ ارسال پست، هشتگ و ویرایش پست موفق است. getChat کانال، linked_chat_id گروه دیدگاه را برمی‌گرداند، اما getChat گروه HTTP 404، getChatMember گروه HTTP 403 و sendMessage مستقیم به گروه HTTP 403 می‌دهند. در رابط، مالک مسیر افزودن بات به گروه دیدگاه را پیدا نکرده است. دیدگاه‌های واقعی کاربران در گروه دیده می‌شوند اما در getUpdates بات نمی‌آیند. وب‌هوک غیرفعال است و دریافت پیام خصوصی بات موفق است.

ارسال sendMessage به خود کانال با reply_to_message_id پست اصلی، پست مستقل جدیدی می‌سازد؛ همان پست نیز به‌صورت خودکار در گروه دیدگاه نمایش داده می‌شود و پاسخ زیر پست اول نیست. پیام بازفرستاده‌شده از گروه به بات، forward_origin نوع user دارد و شناسه گروه/پیام مبدأ را ارائه نمی‌دهد.

لطفاً مسیر رسمی این سه مورد را مشخص کنید:

1. آیا بات مدیر کانال می‌تواند رویداد دیدگاه‌ها را دریافت کند؟ چه مجوز یا تنظیمی لازم است؟
2. برای پاسخ دقیق زیر یک پست، chat_id و reply_to_message_id یا message_thread_id باید از کدام رویداد/متد رسمی به دست آیند؟
3. اگر عضویت/مدیریت جداگانه در گروه دیدگاه لازم است، مسیر رسمی افزودن بات به این گروه چیست؟ آیا linked_chat_id برای متدهای معمول Bot API قابل استفاده است؟

این متن فقط آماده شده و توسط ایجنت به کسی ارسال نشده است. هیچ توکنی نباید به این درخواست اضافه شود.
