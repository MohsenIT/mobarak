# اجرای آزمون واقعی بله

این ابزار فقط پیش‌نیاز اثبات قابلیت را اجرا می‌کند؛ محصول نهایی یا مدرک قبولی E2E نیست. پیاده‌سازی نهایی طبق درخواست TypeScript و Workers/D1 خواهد بود. ابزار تشخیصی مستقل با Python 3 و کتابخانه استاندارد اجرا می‌شود.

## آماده‌سازی مالک

1. بات اختصاصی آزمایش را در @botfather رسمی بله بسازید.
2. کانال و گروه دیدگاه آزمایشی را متصل کنید؛ بات را با مجوز ارسال/ویرایش و دسترسی لازم در هر دو اضافه کنید.
3. توکن را در `.secrets/bale-token` بگذارید؛ پوشه را با مجوز 700 و فایل را با مجوز 600 نگه دارید. توکن را در چت، فرمان یا Git ننویسید.
4. با حساب آزمایشی انسانی به رابط رسمی بله وارد شوید. تنظیم حریم خصوصی بات و مجوزهای مؤثر را در نتیجه آزمون ثبت کنید.

## توالی آزمون

```sh
python3 scripts/bale_probe.py start --channel @TEST_CHANNEL
python3 scripts/bale_probe.py poll
```

دستور start دو پست می‌سازد. در رابط بله، وجود دیدگاه و حضور هر دو پست در دسته‌بندی بومی #باگ را بررسی کنید؛ تنظیم دستی لازم را ثبت کنید. برای هر پست یک دیدگاه و یک پاسخ تو در تو بنویسید و poll را تکرار کنید. رویداد پالایش‌شده باید ارتباط هر دو دیدگاه با پست‌های مختلف را ثابت کند. شناسه گروه به‌تنهایی انتساب به پست را ثابت نمی‌کند. اگر رویداد فاقد ارتباط قابل اثبات است، حدس نزنید و آزمون را ناموفق/نامشخص ثبت کنید.

با شناسه‌های مشاهده‌شده و فقط پس از اثبات انتساب، پاسخ را آزمایش کنید:

```sh
python3 scripts/bale_probe.py reply --chat GROUP_ID --message COMMENT_ID
# فقط اگر message_thread_id در رویداد واقعی مشاهده شد:
python3 scripts/bale_probe.py reply --chat GROUP_ID --message COMMENT_ID --thread OBSERVED_THREAD_ID
python3 scripts/bale_probe.py edit --post 1
```

در رابط بررسی کنید پاسخ بات زیر پست درست است؛ ویرایش متن و تغییر دسته به #بهبود اعمال شده و دیدگاه‌ها حفظ شده‌اند. تا زمان مشاهده رابط، پاسخ موفق API به معنی قبولی نمایش یا دسته‌بندی نیست.

## شواهد و بازیابی

شواهد مسیریابی و زمان UTC در `.phase-zero/evidence.jsonl` ذخیره می‌شوند. متن، نام و شناسه کاربر و URL وب‌هوک حذف می‌شوند. شناسه‌های کانال/گروه برای اثبات اتصال حفظ می‌شوند؛ این فایل نیز پیش‌فرض وارد Git نمی‌شود. نتیجه UI و تنظیمات باید جداگانه در PHASE_ZERO.md ثبت شوند.

ابزار وب‌هوک موجود را حذف نمی‌کند. start تکراری متوقف می‌شود. اگر ارسال timeout شود، درخواست نوشتنی خودکار تکرار نمی‌شود، چون ممکن است روی بله موفق شده باشد؛ ابتدا رابط را بررسی کنید. شروع نیمه‌تمام را با حذف کورکورانه فایل وضعیت تکرار نکنید. polling رویدادهای بات آزمایشی را مصرف می‌کند؛ از بات فعال محصول استفاده نکنید.

## مانع و تصمیم

نبود توکن/مجوز یا خطای شبکه را از نبود قابلیت API جدا ثبت کنید. اگر انتساب یا پاسخ در دیدگاه با API رسمی قابل اثبات نبود، توسعه کامل متوقف می‌ماند. جایگزین قابل پیشنهاد برای تأیید مالک: تکمیل گزارش در گفت‌وگوی خصوصی بات و پیوند به GitHub؛ این جایگزین معیار دیدگاه دوطرفه را برآورده نمی‌کند و بدون تأیید اعمال نمی‌شود.

منبع بررسی، ۲۰۲۶-۱۱-۰۹: https://docs.bale.ai/ — بخش‌های getChat/ChatFullInfo، Message، sendMessage و editMessageText.

## مسیر مستقل پاسخ به پست کانال

عضویت جداگانه در گروه، پیش‌شرط قطعی همه مسیرها نیست. برای آزمایش مسیر پاسخ مستقیم کانال از دستور زیر استفاده می‌شود:

```sh
python3 scripts/bale_probe.py channel-reply --post 1
```

این فرمان `reply_to_message_id` را برابر شناسه پست ثبت‌شده و مقصد را خود کانال قرار می‌دهد. ممکن است نتیجه پست جدید کانال باشد؛ فقط برای آزمون و با بررسی UI اجرا شود. آن را بدون بررسی نتیجه تکرار نکنید. شناسه پست را به‌طور حدسی به‌عنوان `message_thread_id` استفاده نکنید. شرط گروه متصل در دستور `reply` فقط محافظ مسیر ارسال به گروه است و به معنی ضرورت آن مسیر برای محصول نیست.
