# وضعیت موجود پیش از تغییر — ۲۰ آبان ۱۴۰۵

## معماری و استقرار

سرویس TypeScript مستقل در Cloudflare Workers Free با D1، بدون VPS است. حساب جدید و دیتابیس تازه طبق دستور مالک راه‌اندازی شده‌اند؛ داده حساب قبلی منتقل نشده است. نشانی حساب جدید در `.secrets/worker-url` نگه‌داری می‌شود. توکن‌ها در Secrets قرار دارند. مسیر فعال بله webhook رسمی است؛ polling اختیاری پیاده‌سازی شده است.

`bridge-worker` اعتبارسنجی و ثبت inbox؛ `bridge` هماهنگی گزارش/کامنت/وضعیت؛ `api` اتصال رسمی؛ `effects` ثبت اثر خارجی؛ `domain` طبقه‌بندی واژگانی و نمایش؛ `security` HMAC و نام مستعار را مدیریت می‌کنند. مسیر فعلی هر متن خصوصی را پیش‌نویس می‌کند و فقط پس از callback مالک آن را منتشر می‌کند.

GitHub REST با توکن محدود مخزن و webhook امضاشده برای issues و issue_comment متصل است. جدول issues نگاشت شماره و شناسه GitHub به پیام کانال و ریشه گروه را نگه می‌دارد. نگاشت ریشه با متن دقیق پست، فرستنده رسمی کانال و گروه مشخص انجام می‌شود؛ پاسخ در گروه به ریشه ارسال می‌شود. پاسخ مستقیم به پیام کانال، پست مستقل می‌سازد و استفاده نمی‌شود.

## داده و پایداری

events، effects، issues، post_versions، threads، comment_links، drafts، abuse_reports، blocked_users و bridge_settings موجودند. inbox قبل از ack ذخیره می‌شود؛ اثر ارسال مبهم خودکار تکرار نمی‌شود. cron، lease، backoff و reconciliation وجود دارند. پیش‌نویس ۲۴ ساعت اعتبار دارد و محتوای رویداد موفق پاک می‌شود.

## امکانات واقعی API

InlineKeyboard، callback و ویرایش پیام با API رسمی و رابط واقعی قبلاً آزموده شده‌اند. دریافت و انتساب کامنت و پاسخ در ترد واقعی موفق بوده‌اند. هشتگ و فیلتر بومی با مشاهده مالک تأیید شده است. getFile، Photo و Voice در مستندات رسمی تعریف شده‌اند؛ وجود نوع Voice به معنی وجود تبدیل گفتار به متن در محصول نیست. رسانه و تحلیل تصویر تاکنون در پل پیاده‌سازی نشده‌اند.

## Discovery مخزن

REST مخزن در همین روز: Issue Types برابر Task، Bug و Feature؛ labels شامل bug، enhancement، suggestion، documentation، question و duplicate هستند. مسیر ISSUE_TEMPLATE پاسخ 404 داد. Projects پاسخ 404 داد؛ این نتیجه اثبات نبود Projects نیست و ممکن است به قابلیت endpoint یا دسترسی مربوط باشد. پروژه/وضعیت و نوع موازی ساخته نمی‌شود.

## ضعف‌ها

متن آزاد فعلی بدون شفاف‌سازی به پیش‌نویس می‌رود؛ اصلاح از ابتداست؛ FAQ و گفتگو و پیگیری چندکاربره ندارد؛ همه دیدگاه‌های متنی به GitHub منتقل می‌شوند؛ AI و پایش هزینه وجود ندارد؛ عکس پشتیبانی نشده است. تشخیص مشابهت واژگانی است و گزارش قطعی کیفیت معنایی ندارد. توکن AI در فایل محلی موجود است ولی provider و سقف هزینه هنوز از مالک خواسته شده؛ هیچ درخواست پولی انجام نشده است.

## قابلیت‌های محافظت‌شده

رضایت صریح، مالکیت callback، یک اثر ساخت Issue و یک پست برای هر Issue، نگاشت ترد، همگام‌سازی دوطرفه، منبع و نام مستعار، HMAC، retry و توقف اثر مبهم حفظ می‌شوند. قابلیت‌های تازه با migration افزایشی و پرچم فعال‌سازی اضافه می‌شوند. هیچ آزمون عمومی یا هزینه AI بدون مجوز جدید انجام نمی‌شود.

## دانش معتبر و محدودیت آن

نسخه دانش اولیه بر خواندن فایل‌های محلی محصول در همین روز متکی است: NavDrawer، SettingsScreen، LanguageSettings، reader-rendering و mizan. ترجمه خواندن از تفسیر المیزان جداست؛ واژه، ریشه و بن‌واژه یک مفهوم نیستند؛ نمای مصحف و پیوسته متفاوت‌اند. دانش، تاریخ و مسیر منبع دارد و برای پاسخ‌های قطعی باید با نسخه محصول تطبیق داده شود. به‌جای ساخت پاسخ عمومی، فقط FAQ دارای شاهد مستقیم پاسخ داده می‌شود.
