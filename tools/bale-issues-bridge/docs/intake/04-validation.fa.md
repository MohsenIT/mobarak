# اعتبارسنجی نسخه دریافت مشارکت

## آزمون‌های محلی واقعی

- ۱۹ آزمون واحد: هسته قبلی + گزارش روشن بدون سؤال، ابهام جستجو، پیشنهاد، بررسی تخصصی محتوا، حذف اطلاعات تماس، schema، FAQ و نوع فایل.
- TypeScript strict موفق؛ دو تست Python حریم خصوصی موفق.
- SQLite واقعی: اجرای تمام migrationها و trigger اتمیک دریافت متن؛ تکرار شناسه، متن را دوباره اضافه نمی‌کند.
- Miniflare و D1 واقعی محلی با HTTP شبیه‌سازی‌شده: گزارش بدون سؤال، سؤال دکمه‌ای، سقف سؤال، مالکیت callback، کلیک و رویداد تکراری، اصلاح عنوان، دکمه قدیمی، FAQ بدون Issue، Content review، ادامه گفتگو، حریم خصوصی، عکس خصوصی/عمومی پس از رضایت، خطای مدل، بودجه صفر، سقف سه فراخوانی و عدم پرداخت دوباره برای رویداد یکسان.
- همچنین اشتراک گزارش مشابه بدون Issue تازه، حذف تشکر از جریان GitHub، اعلان تغییر مهم به مشترکان خصوصی، عدم ارسال پیام خصوصی به صرف عضویت گروه، و بودجه تعداد query هر پیام بررسی شدند.
- رگرسیون قدیمی ثبت/رضایت، یک پست اصلی، نگاشت ریشه، کامنت دوطرفه، حلقه‌گیری، وضعیت و effect مبهم قبلاً در همین چرخه آزمون موفق داشته است؛ تست نهایی بسته فعلی در CI تکرار می‌شود.

این تست‌ها از API ساختگی استفاده می‌کنند و مدرک کیفیت فارسی یا قیمت واقعی Gemini نیستند. هیچ گزارش آزمایشی عمومی یا فراخوانی پولی انجام نشده است.

## محدودیت‌های صریح

نام provider، endpoint و مجوز سقف هزینه از مالک خواسته شده‌اند و هنوز دریافت نشده‌اند. توکن به‌تنهایی endpoint را مشخص نمی‌کند و نباید برای امتحان به سرویس حدسی ارسال شود. AI خاموش و بودجه صفر است. کیفیت/latency مدل واقعی و E2E مدل پس از دریافت اطلاعات و مجوز هزینه بررسی می‌شود.

ویس به متن، تحلیل بصری و حذف خودکار اطلاعات خصوصی داخل عکس پیاده‌سازی نشده‌اند. کاربر هشدار مرور تصویر را می‌بیند؛ تصویر فقط پس از رضایت عمومی می‌شود. محدودیت اندازه و تعداد و امضای فایل اعمال می‌شود. تطبیق دانش محلی با نسخهٔ منتشرشده سایت هنوز مستقلاً انجام نشده؛ FAQ محدود به شاهد کد است. Projects خواندنی در دسترس نبود؛ هیچ وضعیت یا اولویت موازی ساخته نشده است.

فیلتر مفیدبودن دیدگاه فعلاً قواعد ساده است، نه قضاوت معنایی تضمین‌شده. بازخورد حل‌نشدن، Issue را خودکار باز نمی‌کند. نمایش /my تا ده گزارش اخیر است. سنجه‌ها اهداف عملکرد نیستند و نرخ تکمیل/میانگین سؤال باید بعد از استفاده واقعی محاسبه شود.

## استقرار و آزمون خصوصی

نسخه گفتگو روی حساب جدید Cloudflare مستقر و سلامت intake فعال / AI غیرفعال تأیید شد. CI پل برای commit مربوط به این توسعه موفق شد. پیام /start واقعی و منوی فارسی در رابط بله دیده شد؛ همان پیام به علت تأخیر upstream وب‌هوک با بازیابی رسمی تحویل داده شد. هیچ Issue یا پست عمومی آزمایشی ساخته نشد.

برای رفع تحویل نامطمئن، دریافت بله به polling رسمی با cron دقیقه‌ای تغییر می‌کند؛ وب‌هوک پیش از استقرار با حفظ صف حذف می‌شود و در شکست، نسخه قبلی و وب‌هوک خودکار بازگردانده می‌شوند. GitHub همچنان webhook امضاشده دارد. در صف سبک، پاسخ بله ممکن است حدود یک دقیقه تأخیر داشته باشد؛ backlog می‌تواند آن را بیشتر کند. پاک‌سازی داده‌ها ساعتی و جدا از بودجه query پردازش گزارش انجام می‌شود. این تغییر برای اطمینان تحویل است و ادعای latency لحظه‌ای ندارد.
