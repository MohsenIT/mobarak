# قراردادها و راهبری

ماژول‌های تازه: intake-domain قواعد خالص، schema و ساخت قالب؛ knowledge دانش کوچک نسخه‌دار؛ ai-intake اتصال provider و validation؛ intake کنترل گفتگو؛ attachments دریافت رسمی فایل و انتشار پس از رضایت. bridge همچنان مالک GitHub، کانال و همگام‌سازی است.

migration افزایشی گفتگو، کاربران، subscription، پیوست و سنجه AI را اضافه می‌کند. گفتگو متن پالایش‌شده و گزارش ساختاریافته دارد، نه تاریخچه کامل. هر پردازش نتیجه را قبل از ارسال پیام ذخیره می‌کند و effect پیام کلید پایدار دارد. revision مالکیت callback را محدود می‌کند؛ تأیید نهایی به draft پایدار و کلید ساخت قبلی تبدیل می‌شود.

Schema intake.v1: intent، title، summary، area، current_behavior، expected_behavior، reproduction_steps، environment، missing_critical_info، needs_clarification، next_question، suggested_buttons، privacy_flags، needs_human_review، confidence. نوع، طول، تعداد و کلیدها validate می‌شوند. خروجی مدل داده غیرقابل اعتماد است؛ نمی‌تواند ابزار اجرا کند، URL provider عوض کند، وضعیت GitHub تغییر دهد یا مستقیماً منتشر کند.

Provider از محیط تنظیم می‌شود: endpoint HTTPS سازگار chat completions، model دقیق، AI_API_TOKEN در Secret. endpoint نباید از ورودی کاربر گرفته شود. برای این نسخه تا مشخص‌شدن provider و مجوز هزینه، AI_ENABLED false است. نرخ ورودی/خروجی تومان بر میلیون و بودجه هر گزارش باید صریح باشند؛ صفر یعنی درخواست هزینه‌دار ممنوع. شمار فراخوانی و سقف رزرو توکن قبل از شبکه در D1 مصرف می‌شود؛ retry رویداد هزینه تکراری نمی‌سازد. مدل حداکثر سه بار در مسیر معمول و یک‌بار با اجازه صریح بیشتر فراخوانی می‌شود. متن محدود، دانش مرتبط، timeout، JSON محدود و عدم retry خودکار مدل، هزینه را کنترل می‌کنند. usage واقعی و تأخیر ثبت می‌شود؛ usage ناموجود با رزرو محافظه‌کارانه محاسبه می‌شود. این اعداد تخمین‌اند، نه صورتحساب provider.

جمع‌آوری تصویر فقط PNG/JPEG/WebP، سقف هر تصویر و تعداد، دانلود محدود و بدون redirect خارج از دامنه رسمی بله است. فایل‌های اجرایی، SVG و ویس تبدیل‌نشده منتشر نمی‌شوند. اطلاعات تماس قبل از ارسال AI پالایش می‌شوند. لاگ محتوا و توکن ممنوع است.

انتشار: تست واحد و D1 یکپارچه، migration، Secrets، deploy، سپس فعال‌سازی پرچم INTAKE_ENABLED. بازگشت با خاموش‌کردن پرچم بدون حذف جدول‌ها ممکن است. AI مستقل خاموش می‌شود و مسیر قواعد باقی می‌ماند. آزمون عمومی و آزمون پولی فقط با اجازه مالک انجام می‌شوند. /admin/status سنجه تجمیعی بدون متن خصوصی می‌دهد. حفظ یک پست اصلی، کلید effect و حلقه‌گیری قبلی الزامی است.

نگه‌داری: گفتگو و رسانه خصوصی منقضی پس از هفت روز پاک شوند؛ فراداده و سنجه بدون متن تا سی روز؛ رسانه عمومی برای لینک شواهد نگه‌داری شود. /forget گفتگو خصوصی و اشتراک‌ها را حذف کند. پاک‌کردن محتوای عمومی باید جداگانه و با درخواست مالک بررسی شود.

مسیر فعال دریافت بله پس از تغییر کنترل‌شده، polling رسمی است؛ هیچ حساب انسانی یا API غیررسمی استفاده نمی‌شود. کلید offset بعد از ذخیره پایدار جلو می‌رود. برای بازگشت باید ابتدا polling غیرفعال و سپس وب‌هوک همان سرویس ثبت شود.
